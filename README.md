# CodeGame Academy — Neon Frontend MVP

Bu layihə göndərilən orijinal CodeGame Academy ana səhifəsinin HTML/CSS/JS görünüşünü saxlayır.

## Netlify
Arxivi çıxarın və **index.html olan qovluğu** https://app.netlify.com/drop səhifəsinə sürükləyin. npm, database və API lazım deyil.

## Sınaq
- `index.html` — orijinal ana səhifə, Akademiya, Dərslər, Missiya və münsif baxışı
- `ai-lab.html` — 6 Python missiyası, kod editoru, qayda əsaslı qiymətləndirmə, terminal simulyasiyası, XP, Level və demo sertifikat
- `review.html` — layihənin münsiflər üçün təqdimatı

**Məhdudiyyət:** frontend MVP-də canlı generativ AI, real Python icrası, qeydiyyat serveri və bulud sinxronizasiyası yoxdur. AI mentor təqdimatı qayda əsaslı demodur. İrəliləyiş brauzerin localStorage sistemində qalır.
